## 🎓 Getting Started

### 1. First Login (2 minutes)
```
1. Navigate to /login
2. Enter admin credentials
3. You'll see the dashboard
```

### 2. Add Your First Hotel (5 minutes)
```
1. Click "Hotels" in sidebar
2. Click "Add Hotel" button
3. Fill in the form
4. Click "Add Hotel"
```

### 3. Add Rooms (5 minutes)
```
1. Click "Rooms" in sidebar
2. Click "Add Room" button
3. Select hotel and fill details
4. Upload images
5. Click "Add Room"
```

### 4. Monitor Activity (ongoing)
```
1. Check dashboard daily
2. Review new bookings
3. Track payments
4. Update room status
```

## 🛠️ Troubleshooting

### Common Issues

**Can't Login**
- Verify admin role
- Check credentials
- Clear browser cache

**Hotels Not Showing**
- Refresh the page
- Check network connection
- Verify backend is running

**Images Not Loading**
- Check image URL
- Verify public access
- Try different URL

**Filters Not Working**
- Clear all filters
- Refresh the page
- Try different browser
